# Hands-on: รูปสินค้าในฟอร์มเพิ่มและแก้ไขสินค้า

อัปเดต 2026-07-29 สำหรับ Release 3.0.2

## เป้าหมาย

ตรวจสอบให้ครบทั้งการเลือกรูปจากเครื่อง การถ่ายรูปจากมือถือหรือแท็บเล็ต
การลบรูปที่เพิ่งเลือก และการแทนที่รูปเดิมในหน้าแก้ไขสินค้า

## สาเหตุของบั๊กเดิม

`product-form.js` พยายามเขียนค่าไปยัง `#profitAmount` และ `#profitPercent`
ซึ่งไม่มีอยู่ในฟอร์มปัจจุบัน จึงเกิด JavaScript error ระหว่างโหลดหน้าและสคริปต์
หยุดก่อนผูก `change` event ให้ช่องเลือกรูปและช่องกล้อง

Release 3.0.2 เริ่มระบบ product-image preview ก่อนส่วนคำนวณกำไร ตรวจสอบว่า
element ของกำไรมีอยู่ก่อนใช้งาน เพิ่ม CSS สำหรับสถานะ `[hidden]` และเปลี่ยน
cache key ของ `product-form.js` เป็น `v=3` โดยไม่เปลี่ยน schema หรือ flow
บันทึกรูปฝั่งเซิร์ฟเวอร์

## ทดสอบบน Windows/เดสก์ท็อป

1. เข้าระบบด้วย Manager หรือ Admin แล้วเปิด `สินค้า > เพิ่มสินค้า`
2. กด `เลือกรูปสินค้า` และเลือกไฟล์ JPG, PNG, WEBP หรือ GIF
3. ตรวจว่ารูปตัวอย่างและปุ่ม `ลบรูปที่เลือก` แสดงทันทีโดยไม่ต้อง reload
4. กด `ลบรูปที่เลือก` แล้วตรวจว่า preview หาย
5. เลือกรูปอีกครั้ง กรอกช่องบังคับ และกด `บันทึกสินค้า`
6. เปิดหน้าแก้ไขสินค้าอีกครั้งและตรวจว่ารูปที่บันทึกแสดงเป็นรูปปัจจุบัน

## ทดสอบบนมือถือหรือ iPad/tablet

1. เปิด POS ผ่าน private LAN เช่น `http://192.168.0.200:8002`
2. เปิดฟอร์มเพิ่มหรือแก้ไขสินค้า แล้วกด `ถ่ายรูปสินค้า`
3. อนุญาตกล้องเมื่อ browser ถาม ถ่ายรูปและยืนยันรูป
4. ตรวจว่า preview แสดงทันที ก่อนกดบันทึก
5. ทดสอบ `ลบรูปที่เลือก` แล้วถ่ายใหม่อีกครั้ง
6. บันทึกสินค้าและเปิดหน้าแก้ไขเพื่อตรวจรูปที่จัดเก็บ

`capture="environment"` เป็นคำแนะนำให้ browser ใช้กล้องหลัง พฤติกรรม
หน้าต่างกล้องหรือเมนูเลือกไฟล์อาจต่างกันตาม iOS, Android และ browser

## ทดสอบหน้าแก้ไขสินค้าที่มีรูปเดิม

1. เปิดสินค้าที่มีรูปเดิมและตรวจว่ารูปเดิมแสดงก่อนเลือกไฟล์
2. เลือกหรือถ่ายรูปใหม่และตรวจว่า preview ใหม่แทนรูปเดิม
3. กด `ลบรูปที่เลือก` และตรวจว่ารูปเดิมกลับมา
4. ออกจากหน้าโดยไม่ submit แล้วกลับเข้ามา รูปเดิมต้องไม่เปลี่ยน
5. เลือกรูปใหม่และ submit จากนั้นรูปใหม่จึงเป็นรูปปัจจุบัน
